#  Sistema Veterinario en Python

Este proyecto es una aplicación de consola escrita en Python que permite registrar, buscar, eliminar, listar y contar mascotas. Además, se desarrolló una guía de testing que aplica técnicas estáticas y dinámicas de acuerdo con los estándares de calidad del software.

---

## 📋 Características del Sistema

- Registro de mascotas con nombre, especie, edad y dueño.
- Búsqueda de mascotas por nombre.
- Eliminación de mascotas.
- Listado de todas las mascotas registradas.
- Conteo total de mascotas.
- Menú interactivo por consola.

---

### 🔍 Tipos de testing aplicados:

- ✅ Revisión estática del código (`Pylint`)
- 🧪 Pruebas unitarias automatizadas con `pytest`
- 🔗 Pruebas de integración (registrar → buscar - registrar → eliminar)
- 📋 Pruebas funcionales manuales
